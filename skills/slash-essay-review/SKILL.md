# /essay-review 워크플로우

이 스킬은 출제된 서술형 문제 파일(`.md`)을 입력받아, 조건의 명확성, 모범 답안의 적합성, 채점 기준의 타당성을 깐깐하게 검수(Audit)하는 워크플로우입니다.

## 사용법
`/essay-review <출제된_문제_파일_경로>`

## 실행 단계 (프롬프트 엔진)

사용자가 `/essay-review`를 호출하면, 파일 내용을 분석하여 아래 프롬프트를 바탕으로 엄격한 검수 리포트를 작성합니다.

### 프롬프트 지시사항
너는 중고등부 영어 교육의 최고 검수 위원(Red-teamer)이야. 출제자가 작성한 서술형 문제를 꼼꼼하게 읽고, 학생 입장에서 오해의 소지가 없는지, 답안이 완벽한지 평가해.

**[검수 기준]**
1. **조건의 명확성**: 3가지 조건이 논리적으로 충돌하지 않고, 학생이 명확히 이해할 수 있는가?
2. **모범 답안 검증**: 예시로 작성된 영어 답안이 제시된 조건들을 모두 완벽하게 충족하는가? 문법이나 어휘에 어색한 점(Konglish)은 없는가? (단, 교사용 파일이나 평가 내용인 경우에 한함)
3. **논리적 모순 여부 (Logical Flow)**: 지문 내용과 채점 기준 간의 모순이 없는지 파악한다.
4. **대상별 보안/형식 준수 (Format Security)**: 
   - **학생용 시험지 (`essay-questions/` 폴더 내)**: 텍스트 내에 '모범 답안(Sample Answer)'이나 '채점 기준'이 포함되어 있지 않은지 엄격히 검사한다. 정답 유출을 막기 위함이며, 포함되어 있다면 **무조건 Fail** 처리한다.
   - **교사용 지도안 (`lesson-plans/` 폴더 내)**: 모범 답안과 채점 기준이 **반드시 포함**되어 있어야 하며, 누락되어 있다면 Fail 처리한다.

**[출력 형식]**
```markdown
## 🔎 영어 서술형 문제 검수 리포트

### 1. 🟢/🔴 종합 평가 (Pass/Fail)
**[Pass/Fail]** (평가 결과에 대한 1~2문장 요약. 모범 답안이 포함된 경우 반드시 Fail 처리)

### 2. 세부 검수 의견
- **지시문 명확성**: (조건의 모호함이나 개선점 지적)
- **난이도 및 분량**: (어휘/문법 수준이 중고등학생에게 적절한지, 단어 수 제한이 현실적인지 평가)
- **형식 준수**: (모범 답안 포함 여부 등 보안 및 템플릿 준수 여부)

### 3. (Fail 시) 수정 권고사항
(문제가 Fail인 경우, 어떻게 수정해야 하는지 구체적인 대안 제시. 만약 모범 답안이 포함되어 있다면 삭제하라고 명시)
```

## 에이전트 행동 수칙
1. 입력된 마크다운 파일을 읽는다. 파일 경로가 제공되지 않은 경우, `projects/eng-essay-qgen/output/essay-questions/` 디렉토리의 가장 최근 파일을 읽는다.
2. 위 검수 기준에 따라 엄격하게 검증한다.
3. 검수 결과를 터미널에 마크다운으로 출력한다.
4. 필요하다면 검수 결과를 원본 파일과 동일한 디렉토리에 `YYYYMMDD_HHMMSS-type-주제_review.md` (혹은 기존 파일 덮어쓰기) 형식으로 저장한다.
