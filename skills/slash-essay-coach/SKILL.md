# /essay-coach 워크플로우

학생의 의도와 현재 영어 수준을 보존하면서 스스로 다음 글을 더 잘 쓸 수 있는 진단과 첨삭을 제공한다. 점수보다 오류의 원인, 수정의 우선순위, 재사용 가능한 쓰기 전략에 집중한다.

## 사용법

```text
/essay-coach "<학생_영작>" [학년]
/essay-coach <학생_답안.txt|md> [학년]
/essay-coach <문제지.md> "<학생_영작>" [학년]
/essay-coach <학생_답안_이미지> [학년]
```

- 학년은 `중1`, `중2`, `중3`, `고1`, `고2/3` 중 하나로 정규화한다. `고2`와 `고3`은 모두 `고2/3`으로 취급한다.
- 문제지나 루브릭이 있으면 명시된 조건만 분석한다. 없으면 과제 충족도를 추측하지 말고 `판단 보류`로 표시한다.
- 사용자가 초점을 지정하면 `문법`, `내용`, `구성`, `어휘`, `전체` 중 해당 범위에 집중한다. 기본값은 `전체`다.
- 점수와 감점을 요구하면 이 스킬에서 임의로 계산하지 말고 `/essay-grade` 워크플로우를 사용한다.

## 실행 단계

### 1. 입력을 확정한다

1. 텍스트 입력은 철자, 대소문자, 문장부호를 바꾸지 않고 원문으로 보존한다.
2. 파일 입력은 답안과 문제지 또는 루브릭을 구분하여 읽는다.
3. 이미지 입력은 보이는 글을 그대로 전사하고, 분석 전에 사용자에게 다음 문구로 확인을 요청한 뒤 멈춘다.

   `텍스트가 올바르게 추출되었는지 확인해주세요. 수정할 부분이 없다면 '진행'이라고 승인해주세요.`

4. 승인 전에는 이미지 답안을 첨삭하거나 평가하지 않는다. 판독이 불확실한 부분은 임의로 메우지 말고 `[판독 불확실: 후보1 / 후보2]`로 표시한다.

### 2. 분석 기준을 적응형으로 정한다

1. 문제지가 있으면 목적, 독자, 장르, 분량, 필수 내용, 인용, 문법 조건을 먼저 추출한다.
2. 학생의 학년과 글의 실제 특성에 맞춰 분석 비중을 조절한다. 고정된 오류 개수나 획일적인 문법 목록을 강제하지 않는다.
3. 다음 다섯 영역을 검토하되 실제 글과 사용자 초점에 필요한 영역만 상세히 다룬다.
   - 과제 및 내용: 질문에 대한 응답, 근거, 정확성, 충분성
   - 구성 및 응집성: 중심 생각, 문장 순서, 연결, 반복
   - 문장 및 문법: 문장 완결성, 어순, 시제, 일치, 관사, 전치사
   - 어휘 및 문체: 의미 정확성, 자연스러운 결합, 학년과 장르에 맞는 어조
   - 표기: 철자, 대소문자, 문장부호
4. 개선 항목을 `핵심`, `중요`, `다듬기`로 구분하고, 같은 원인에서 생긴 반복 오류는 하나의 패턴으로 묶는다.

### 3. 근거를 붙여 첨삭한다

1. 각 항목을 `명백한 오류`, `개선 제안`, `의미에 따른 선택` 중 하나로 판정한다.
2. 원문의 짧은 구절, 학생이 이해할 수 있는 한국어 설명, 의미를 가장 적게 바꾸는 수정안을 함께 제시한다.
3. 허용되는 영미식 영어 차이와 문체 선택을 오류로 단정하지 않는다. 한 글 안에서 일관성이 깨진 경우에만 설명한다.
4. 원문의 의도나 사실을 확정할 수 없으면 가능한 수정안을 나누어 제시한다. 학생이 쓰지 않은 주장, 근거, 경험을 사실처럼 추가하지 않는다.
5. 지문 직접 인용 조건이 있으면 인용문의 원문 일치 여부를 확인하고, 인용 자체를 문법 교정한다는 이유로 바꾸지 않는다.

### 4. 두 단계 수정본을 만든다

1. `최소 수정본`에서는 객관적인 오류만 고치고 생각, 문장 순서, 분량, 학년 수준을 최대한 유지한다.
2. `발전 수정본`에서는 같은 주장과 근거 안에서 연결과 자연스러움을 개선한다. 새로운 핵심 아이디어나 근거는 넣지 않는다.
3. 최소 수정본을 완성한 뒤 원문과 문장별로 다시 대조하여 일치, 동사 형태, 시제, 가산명사의 수와 한정사, 어형, 철자와 문장부호의 명백한 오류가 남지 않았는지 확인한다.
4. 사용자가 분석만 요청했거나 수정본을 원하지 않으면 해당 수정본을 생략하고 그 사실을 명시한다.
5. 발전 수정본이 원문보다 어려워졌다면 학생이 재사용할 표현을 2~3개만 골라 뜻과 쓰임을 설명한다.

### 5. 결과를 생성하고 저장한다

1. `templates/writing_feedback_prompt.j2`의 출력 계약을 적용한다.
2. 상위 개선 과제는 최대 3개로 압축하되, 명백한 오류의 최소 수정은 누락하지 않는다.
3. 마지막에 학생이 직접 고쳐 쓸 문장 1개와 확인 질문을 제시한다. 곧바로 정답을 덧붙이지 않는다.
4. 결과를 `output/lesson-plans/YYYYMMDD_HHMMSS-coach-식별자.md`에 저장한다. 학생용 문제지가 있는 `output/essay-questions/`에는 수정본이나 답안을 저장하지 않는다.
5. 사용자가 PDF를 원하면 다음 형식으로 렌더링한다.

```bash
python3 tools/exam-pdf/make_exam_pdf.py <저장된_마크다운> --title "영어 글쓰기 진단 및 첨삭" --subtitle "[학년] 맞춤 피드백"
```

## 품질 기준

- 친절하되 모호하게 칭찬하지 말고 원문 근거를 제시한다.
- 문법 용어보다 학생이 다음 글에 적용할 수 있는 짧은 규칙과 예시를 우선한다.
- 한 문장을 완전히 대신 써 주는 것보다 학생이 선택하고 다시 쓰게 하는 피드백을 우선한다.
- 초안에 없는 과제 조건, 배점, 학생 이름을 만들어 내지 않는다.
- PDF로 변환할 출력에는 이모지와 XeLaTeX에 취약한 장식용 특수 기호를 사용하지 않는다.
