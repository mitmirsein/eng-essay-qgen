# /essay-grade 워크플로우

이 스킬은 학교 현장의 채점 부담을 줄이고 학생들에게 즉각적인 맞춤형 피드백을 제공하기 위한 **학생 답안 자동 채점 엔진**입니다.

## 사용법
1. **텍스트 채점**: `/essay-grade <문제지_마크다운_경로> "<학생_답안_텍스트>"`
2. **단일 이미지 채점**: `/essay-grade <문제지_마크다운_경로> <이미지_파일경로>`
3. **일괄 채점(Batch)**: `/essay-grade <문제지_마크다운_경로> --batch` (이 경우 `input/answer-sheets/` 폴더 안의 모든 이미지를 순회하며 채점)

- `<문제지_마크다운_경로>`: 출제 시 생성된 `.md` 파일 경로 (채점 기준 포함)
- `"<학생_답안_텍스트>"`: 텍스트 입력 시 따옴표로 묶어 입력
- `<이미지_파일경로>`: 학생이 제출한 답안지 캡처 파일 경로 (예: `.jpg`, `.png`)

## 실행 단계 (VLM & HITL 프롬프트 엔진)

사용자가 `/essay-grade`를 호출하면 다음과 같은 순서로 진행됩니다.
1. **입력 판별**: 텍스트인지, 단일 이미지인지, 배치 모드(`--batch`)인지 파악합니다.
2. **추출(Extraction)**: 이미지 입력 시 에이전트의 비전(Vision) 기능을 사용하여 손글씨를 텍스트로 읽어냅니다.
3. **검수(Validation / HITL)**: 인식된 텍스트를 터미널에 출력하고 사용자의 **승인(Confirm) 혹은 수정 지시**를 대기합니다. (배치 모드 시 한 명씩 추출 -> 검수 -> 채점 반복)
4. **채점(Grading)**: 추출/검수 완료된 학생 답안을 `templates/grading_prompt.j2` 프롬프트에 주입하여 자동 채점을 진행합니다.

### 지시사항 (가이드라인)
1. 이미지 텍스트 인식 시 오류로 인해 억울한 감점이 발생하지 않도록, 반드시 사용자에게 **"텍스트가 올바르게 추출되었는지 확인해주세요. 수정할 부분이 없다면 '진행'이라고 승인해주세요."**라고 묻고 멈춰야 합니다.
2. 프롬프트 로직에 따라 학생 답안이 각 채점 조건(분량, 내용, 문법)을 충족했는지 엄격히 분석합니다.
3. 문법/어휘 오류 발견 시, 어떤 부분이 틀렸는지 명시하고 오류 1개당 0.5점을 감점하여 최종 점수를 도출합니다.

## 에이전트 행동 수칙
1. `<문제지_마크다운_경로>` 파일을 읽어 채점 기준표를 파악한다.
2. 입력값이 텍스트인 경우 즉시 3번으로 넘어가고, 이미지(또는 `--batch`)인 경우 VLM을 통해 텍스트를 추출한 뒤 **사용자 승인을 받는다**.
3. 학생의 답안(최종 텍스트)과 파악한 채점 기준을 바탕으로 `templates/grading_prompt.j2` 프롬프트를 실행한다.
4. 생성된 **💯 자동 채점 리포트** 마크다운을 터미널에 깔끔하게 출력한다.
5. **결과물 저장**: 파일 쓰기 도구를 사용해 `output/lesson-plans/` 폴더에 `YYYYMMDD_HHMMSS-grade-학생명.md` 형식으로 저장한다.
6. 파일 저장이 완료되면, `tools/exam-pdf`를 사용하여 채점 피드백을 PDF로 변환한다. (학생 배포용)
   - 실행 명령어: `python3 tools/exam-pdf/make_exam_pdf.py [저장된_마크다운_경로] --title "자동 채점 피드백 리포트" --subtitle "[학생명]"`
7. 배치 모드(`--batch`)인 경우, PDF 변환 완료 후 `input/answer-sheets/` 내의 다음 이미지 파일로 넘어가 2번부터 반복한다. 모든 파일 처리가 끝나면 결과를 종합 보고한다.
