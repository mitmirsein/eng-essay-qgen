# /auto-essay 오케스트레이터 워크플로우

이 스킬은 영어 서술형 출제 및 수업 준비의 전 과정을 지휘(Orchestrate)하는 마스터 스킬입니다. 사용자가 구체적인 지문 파일 대신 **주제(대략적인 내용)**와 **학년 수준**만 제시해도 처음부터 끝까지 자동으로 완결된 시험지와 교안을 만들어 냅니다.

## 사용법
`/auto-essay "주제 또는 대략적인 내용" [학년: 중1/중2/중3/고1/고2/고3] [type1|type2|type3]`

예시:
- `/auto-essay "기후 변화로 인한 북극곰의 위기" 중2 type2`
- `/auto-essay "소셜 미디어가 십대에게 미치는 영향" 고1 type1`
- `/auto-essay "스마트폰 중독을 고민하는 친구에게 쓰는 편지" 중1 type3`

* `type1`: 단일 지문, 문학/추론/인물 분석 중심의 출제 방향 지정 (선택)
* `type2`: 복수 지문, 비문학/요약/종합 분석 중심의 출제 방향 지정 (선택)
* `type3`: 실용문/의견 제시 중심, 고민 상담 및 찬반 논쟁에 대한 조언/해결책 영작 (선택)
*(※ 템플릿 엔진은 이제 하드코딩된 조건을 쓰지 않으며, 학년과 지문 특성(및 지정된 type 방향성)을 분석하여 어휘 수, 필수 문법 등의 세부 조건을 알아서 적응형(Adaptive)으로 설계합니다.)*

## 학년별 난이도 매핑 가이드라인
지문을 생성하고 문제를 출제할 때, 다음의 교육과정 기준에 맞추어 난이도와 서술 조건을 엄격히 조절하라.
- **중1 (Middle 1)**: 친숙한 일상적 주제(가족, 취미, 날씨 등), 단순 현재/과거 시제, 기초 어휘, 짧은 단문 위주 (지문 길이 60~80단어).
- **중2 (Middle 2)**: to부정사, 동명사, 비교급, 접속사(when, because 등) 활용. 짧은 문단 단위의 논리 전개 (지문 길이 80~110단어).
- **중3 (Middle 3)**: 관계대명사, 현재완료, 수동태 등 중학 필수 구문 포함. 사회, 문화, 환경 등 약간 확장된 주제 (지문 길이 110~140단어).
- **고1 (High 1)**: 분사구문, 관계부사, 복문 구조. 추상적 개념(심리, 과학 등) 도입, 고등 모의고사 지문 수준 (지문 길이 130~170단어).
- **고2, 고3 (High 2/3)**: 수능 수준의 고난도 어휘, 복잡한 구문(가정법, 도치 등), 학술적/철학적 주제, 정교한 논리 구조 (지문 길이 150~200단어).

## 오케스트레이션 실행 단계 (에이전트 수칙)

에이전트는 사용자의 요청을 받으면 **아래의 순서대로 하위 스킬과 툴을 직접 연쇄 호출하여** 작업을 완수하라. (별도의 사용자 개입 없이 한 번에 진행할 것)

### Phase 1: 지문 자동 생성 (Passage Generation)
1. 사용자가 제시한 주제와 학년을 바탕으로 **[학년별 난이도 매핑 가이드라인]**에 맞는 고품질 영어 지문을 생성한다.
2. 만약 문제 유형이 `type2`라면, 대조되거나 보완되는 2개의 문단 (A), (B)로 구성된 지문을 생성해야 한다.
3. 생성된 지문을 `projects/eng-essay-qgen/passages/` 폴더에 `YYYYMMDD_HHMMSS-type-주제.txt` 형식으로 저장한다. (예: `20260801_123000-type1-climate_change.txt`)

### Phase 2: 서술형 문제 출제 (/essay-qgen 연동)
1. Phase 1에서 생성한 지문 텍스트(또는 파일 경로)와 입력받은 학년, type 정보를 바탕으로 **`/essay-qgen` 스킬의 로직을 실행**한다. (해당 스킬의 규칙을 참조하되, 지문이 주어졌으므로 바로 출제를 시작하라.)
2. 문제 출제 시, 입력된 학년 수준에 맞게 문항의 지시문과 조건의 난이도를 조절한다.
3. 출제된 문제를 `output/essay-questions/` 경로에 `.md` 파일로 저장한다. (단, `make_exam_pdf.py` 실행 시 `--subtitle "[학년] 영어 서술형 평가"` 로 부제목을 지정하라.)

### Phase 3: 문제 검수 (/essay-review 연동)
1. Phase 2에서 출제된 문제를 **`/essay-review` 스킬의 기준에 따라 엄격히 검수**한다.
2. 검수 결과 '모범 답안'이 포함되어 있거나 기타 사유로 **Fail** 판정을 받은 경우, 에이전트 스스로 문제를 즉시 수정하고 기존 마크다운 파일을 덮어쓴다.

### Phase 4: 교안 작성 (/lesson-plan 연동)
1. 수정을 통과한 최종 문제를 바탕으로 **`/lesson-plan` 스킬의 로직을 실행**하여 교사용 수업 지도안을 작성한다.
2. 교안 생성 시 해당 학년의 성취기준을 반영해야 한다.
3. 교안을 `output/lesson-plans/` 폴더에 `.md` 파일로 저장하고 PDF를 생성한다. (`--subtitle "[학년] 영어 서술형 대비"`)

### Phase 5: 최종 보고
전체 파이프라인이 완료되면, 사용자에게 **각 단계별 결과물(지문, 문제지 PDF, 교안 PDF)의 경로와 간략한 요약을 보고**하고 종료한다.
