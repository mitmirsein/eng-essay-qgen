# 2022 개정 영어과 reference 출처

이 파일의 코드는 생성 모델의 기억으로 채우지 않고, 공식 교육기관 자료에서 확인한 뒤 `curriculum-2022.json`에 기록한다. 코드의 학교급/과목 구분은 원문을 유지하며, 프로젝트의 `고2/3` 정규화는 assessment metadata에만 적용한다.

- [NCIC 중등 영어 성취수준 자료실](https://ncic.go.kr/board/B0024.cs?act=read&bwrId=2031&m=10&pageIndex=1&pageUnit=15): 중등 영어 PDF와 원문 다운로드를 제공하는 국가교육과정정보센터 페이지.
- [경기도교육청 중등 영어 수업 설계 자료](https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202401040956090010.pdf): `9영03-*`, `9영04-*` 읽기·쓰기 코드 확인에 사용.
- [경기도교육청 2022 개정 중학교 성취수준 자료](https://www.goe.go.kr/resource/old/BBSMSTR_000000030062/BBS_201812310813583710.pdf): 원인·결과 추론과 의견 쓰기 코드 확인에 사용.
- [경기도교육청 공통영어 1 최소 성취수준 자료](https://www.goe.go.kr/resource/old/BBSMSTR_000000030224/BBS_202503100916461190.pdf): `10공영1-*` 코드와 수행 진술 확인에 사용.
- [경기도교육청 공통영어 1 논술형 평가 자료](https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202502250541471270.pdf): 요약·의견·표현 점검 관련 `10공영1-02-*` 코드 확인에 사용.
- [경기도교육청 영어 II 최소 성취수준 자료](https://www.goe.go.kr/resource/old/BBSMSTR_000000030224/BBS_202503140951129581.pdf): `12영Ⅱ-01-03` 코드 확인에 사용.
- [경기도교육청 고등학교 영어 II 수업 설계 자료](https://www.goe.go.kr/resource/goe/na/bbs_2675/2026/02/ed0f7745-745f-4312-9a96-e6e304c646fb.pdf): `12영Ⅱ-02-05` 코드 확인에 사용.
