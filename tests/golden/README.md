# Golden lesson-plan review

이 디렉터리는 유형별 교안 구조 회귀 fixture입니다. 자동 검증은 schema, 수업 시간 합계,
교육과정 코드, 발문-예상 반응-확인 방법의 정합성을 검사합니다.

사람 검토자는 각 파일에 대해 다음을 확인한 뒤 별도 승인 기록을 남깁니다.

- 10분 이내에 수업 목표와 준비물을 파악할 수 있는가
- sequence를 그대로 따라갈 수 있는가
- 예상 반응과 오개념 대응이 실제 지문에 근거하는가
- support, core, extension이 같은 평가 목표를 유지하는가
- 답안 계획과 채점 앵커가 경계 사례를 설명하는가

자동 검증 통과는 교육적 승인과 동일하지 않습니다.
